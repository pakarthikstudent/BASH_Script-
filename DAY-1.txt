Task-4
-------------
Write a shell script
-> read disk partition name from <STDIN> (ex: /dev/xvdb1)
-> read disk partition size from <STDIN> (ex: 120)
|
-> read another disk partition name from <STDIN> (ex: /dev/xvdd1)
-> read disk partition size from <STDIN> (ex: 200)
|
Calculate sum of partition size <==
|
-> use - echo - display each input partition name and size
		display total size
--------------------------------------------
read -p "Enter a disk partition1:" p1
read -p "Enter $p1 size:" s1

read -p "Enter a disk partition1:" p2
read -p "Enter $p2 size:" s2
total=`expr $s1 + $s2`

echo "
Partition: $p1	  Size:$s1
-------------------------------
Partition: $p2    Size:$s2
-------------------------------
Total Size: $total 
-------------------------------"
