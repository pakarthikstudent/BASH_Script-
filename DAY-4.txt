awk internal operations
--------------------------
awk -option '/pattern/{Action}' input
    -F<sep>
1. READ - read data from <INPUT> ->stored to buffer
2. SPLIT - on the buffer -> split each line into multiple columns based on delimiter (default sep is space) 
3. SEARCH
4. ACTION
				awk -F: '/bash/{print}' IP
IP
----------------
userA:bin:bash
userB:bin:ksh
userC:bin:bash
-----------------

		1 userA:bin:bash
		------------------
		2 userB:bin:ksh
		------------------
		3 userC:bin:bash
		------------------
	-F<sep>	
		1 userA|bin |bash
		-------|----|-----
		2 userB|bin |ksh
		-------|----|-----
		3 userC|bin |bash
		-------|----|-----

		
		NR  $1    $2   $3 <== awk - special variables

		-------|----|-----
		2 userB|bin |ksh
		-------|----|-----
		3 userC|bin |bash
